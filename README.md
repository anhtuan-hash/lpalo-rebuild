# LPALO Rebuild

An independent, Vercel-ready recreation of the playful podcast discovery experience inspired by lpalo.com.

## Local development

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import this repository in Vercel. The framework preset is **Next.js** and no environment variables are required.

This project uses newly written code and replacement illustrations/content; it does not include the original site's proprietary source or media assets.
